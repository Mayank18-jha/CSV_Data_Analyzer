# CSV Data Analyzer

## Problem Statement
Raw CSV data often contains missing values and duplicates. This project cleans and analyzes CSV data using Python.

## Features
- Load CSV data
- Handle missing values
- Remove duplicates
- Generate summary statistics
- Export cleaned CSV

## Tech Stack
- Python
- Pandas
- NumPy

## How to Run
1. Install dependencies  
   pip install -r requirements.txt
2. Run the script  
   python analyzer.py

## Output
- Cleaned CSV file
- Console summary statistics
